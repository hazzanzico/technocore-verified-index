# Governance

## Equal treatment

Every project, including projects owned by this index's maintainer, is evaluated
by the same published code and point weights. Catalog order and table order do
not depend on score, stars, ownership, or personal relationships.

The maintainer currently owns `hazzanzico/technocore-signed-action`. That
conflict is disclosed here and in generated reports. Changes that could affect
its score must change the public rubric for every project and include tests.

## Adding and correcting entries

Pull requests may add projects, correct neutral descriptions, or point to a
specific in-repository protocol evidence file. The automated report is never
edited by hand. Disputed observations should include the GitHub API field or
repository path that demonstrates the correction.

## Removal

Projects are removed only when they are unrelated, maliciously represented,
deleted, or requested for removal by their owner. Archived or temporarily
unavailable projects normally remain visible with their observed state so the
index does not silently rewrite history.

## Changes to scoring

Scoring changes require:

1. a methodology update;
2. tests for new and existing boundaries;
3. regeneration of all projects under the same rule; and
4. a changelog entry describing who benefits or loses points.
